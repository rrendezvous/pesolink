# PESO-Link MisOr User Manual

PESO-Link MisOr is an Android app for PESO Misamis Oriental. It helps job seekers prepare their National Skills Registration Program (NSRP) profile, get it verified once by PESO, and apply to jobs with a PESO referral. Employers post jobs and review PESO-referred applicants, and PESO Admin verifies profiles and monitors the whole process.

This manual explains how each user role uses the app, step by step. It covers **PESO-Link MisOr version 1.0.0** for Android.

## Who uses the app

| Role | How they get an account | What they do |
|---|---|---|
| **Job seeker** | Creates their own account in the app | Fills in the NSRP profile (by typing or with the optional form scan), submits it to PESO, finds jobs, applies with PESO referral, and tracks applications |
| **Employer** | PESO Admin creates the account after PESO approves the employer's requirements outside the app | Posts jobs, reviews PESO-referred applicants, and updates their application status |
| **PESO Admin** | Given by PESO | Verifies or returns NSRP profiles, monitors referrals, manages employer accounts, and monitors job posts |

## Key terms

| Term | Meaning |
|---|---|
| **APK** | The installer file of an Android app. PESO-Link MisOr is installed from an APK given by the team. |
| **Tab** | The buttons at the bottom of the screen (for example Home, Jobs, Alerts) that open each part of the app |
| **Filter** | The row of buttons above a list (for example All, Full-Time, For Review). Tap one to show only those items. |
| **NSRP profile** | The job seeker's profile in the app, laid out like NSRP Form 1 (DOLE, January 2017). Each job seeker has one. |
| **PESO-Verified** | PESO has checked the job seeker's NSRP profile. This is done once. |
| **PESO-Referred** | An application sent by a PESO-Verified job seeker. Every application from a verified job seeker is PESO-referred. |
| **Skill comparison** | A list of the job's required skills that the job seeker has (matched) and does not have (missing). It is only a comparison; it does not rank applicants or decide who is hired. |
| **OCR form scan** | An optional tool that reads a photo of a filled-in NSRP form and fills in the profile fields. The job seeker must check every field before saving. |
| **Alerts** | Notifications inside the app. The app does not send text messages or emails. |
