# PESO-Link MisOr Frontend

This Expo React Native frontend is submitted as an Android-focused mobile application for PESO-Link MisOr.

## Official Target

- Android is the official capstone target.
- `npm start` and `npm run android` both start the Android-focused development flow.
- `npm run ios:preview` is available only for developer preview through Expo Go because the developer has an iPhone.
- `npm run web:preview` is not part of the submitted deployment scope.

## Run

```bash
npm install
npm run android
```
