# NSRP OCR Sample Images

Use these images when demonstrating or testing the Upload NSRP OCR feature.

- `nsrp-page-1-sample.jpg`: personal information, contact details, job preference, and profile fields.
- `nsrp-page-2-sample.jpg`: education, training, work experience, and other skills.

Demo order:

1. Upload `nsrp-page-1-sample.jpg`.
2. Review the editable OCR fields.
3. Upload `nsrp-page-2-sample.jpg`.
4. Review the merged fields.
5. Save only after checking the data.
